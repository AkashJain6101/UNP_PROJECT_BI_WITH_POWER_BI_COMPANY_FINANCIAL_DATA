# UNP_PROJECT_BI_WITH_POWER_BI_COMPANY_FINANCIAL_DATA

I have worked on a company's financial dataset using Power BI, as part of a value-added course completed with UNP Education. My analysis provides key insights into sales performance, profit trends, regional profitability, discount impact, and product performance. The findings highlight a 249.46% profit growth, variations in profit margins across regions, and the performance of high and low-margin products. Based on these insights, I have suggested strategic recommendations to optimize pricing, discounting, inventory management, and sales expansion for sustained business growth.
